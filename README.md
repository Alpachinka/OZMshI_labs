# Розпізнавання трьох образів (коло / квадрат / трикутник) — Brain.js + Web Workers

Лабораторні роботи 1–4, варіант 5, дисципліна «Опрацювання зображень».
Браузерна аплікація: генерує набір зображень (групи Assets: іконки 32×32 PNG, середні 256×256 JPG, якісні 4K JPG),
навчає нейромережу [Brain.js](https://github.com/BrainJS/brain.js) і розпізнає образ на вхідному зображенні.

## Запуск
1. Завантажте репозиторій і відкрийте **`index.html`** у Chrome / Edge (подвійний клік). Сервер і встановлення не потрібні.
2. Або відкрийте опубліковану сторінку (GitHub Pages): `https://<ваш-логін>.github.io/<репозиторій>/`.

## Як користуватись
1. **Згенерувати набір** (за замовчуванням 900 зображень) — або «Завантажити папку…» зі структурою `Assets/<група>/<circle|square|triangle>/файл`.
2. Позначити групи (папки), на яких вчити; задати **кількість епох** і **швидкість навчання**; «Навчити мережу».
3. Завантажити файл або «Випадкова фігура» → «Розпізнати образ».
4. Блок «Експерименти»: серія «набір × швидкість × епохи» з повторами та бенчмарк розпаралелення (результат — таблиця + CSV).
5. Лог операцій і таймер — у нижній частині та шапці сторінки.

## Архітектура
| Частина | Роль |
|---|---|
| Основний потік | Інтерфейс, прогрес, лог, таймер |
| Пул Web Workers | Паралельна генерація, кодування/декодування та побудова ознак (256 чисел) для зображень |
| Воркер нейромережі | Brain.js: навчання (епоха за епохою) і розпізнавання |

Мережа: 256 → 32 → 3 (сигмоїда). Розбиття даних: 80 % навчання / 20 % тест.

## Структура репозиторію
```
index.html                 # готова сторінка (Brain.js вбудовано) — просто відкрити
src/app.template.html      # вихідний код аплікації (без бібліотеки)
vendor/brain.browser.js    # Brain.js 2.0.0-beta.24 (збірка для браузера)
build.py                   # python build.py  → збирає index.html із шаблона
```

## Збірка
```
python build.py
```

## Версії та вимоги
Brain.js 2.0.0-beta.24; браузер з підтримкою OffscreenCanvas і Web Workers (Chrome / Edge / Firefox / Safari 16.4+).
